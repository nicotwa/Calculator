## README - Calculator

# Python Calculator

A simple calculator build with Python.
This project performs basic arithmetic operations and handles user input.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Error handling (division by zero)
- Continuous calculations with loop

## What I learned
- Using conditions (if/elif/else)
- Handling user input
- Preventing errors (e.g. division by zero)
- Writing simple program logic

## How to run
1. Make sure Python is installed
2. Run the file:
```bash
python main.py
